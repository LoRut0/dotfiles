# Навигация в Neovim внутри VS Code

Шпаргалка под текущую конфигурацию LazyVim и расширение **VS Code Neovim**.
Свои сочетания заданы в [vscode-keymaps.lua](lua/config/vscode-keymaps.lua).

Все Vim-команды ниже вводятся в **Normal mode**: сначала нажми `Esc`.
Буквы нажимай последовательно: `gai` — это `g`, затем `a`, затем `i`.
`Ctrl+w` означает одновременное нажатие. Лидер — **`\`**, поэтому `\ff`
означает `\`, затем `f`, затем `f`.

## Определения, использования и история

Поставь курсор на имя функции, переменной или типа.

| Клавиши | Действие |
| --- | --- |
| `gd` | Перейти к определению |
| `gD` | Посмотреть определение во всплывающем окне — Peek Definition |
| `gf` | Перейти к объявлению — удобно для C++-заголовков |
| `gF` | Посмотреть объявление во всплывающем окне |
| `gr` | Найти места использования символа — References |
| `gai` | Показать функции, вызывающие текущую — Incoming Calls |
| `gb` / `gB` | Назад / вперёд по истории переходов |
| `Ctrl+o` / `Ctrl+i` | Те же назад / вперёд через расширение |
| `K` или `gh` | Показать документацию и тип под курсором |
| `Ctrl+w`, затем `gd` | Открыть определение в соседней группе редактора |

**References** показывает использования символа, в том числе передачу функции
как значения. **Incoming Calls** показывает вызывающие функции. Для обоих
нужна поддержка языка в VS Code и индекс проекта.

`gD` и `gf` здесь работают по
[сочетаниям расширения VS Code Neovim](https://github.com/vscode-neovim/vscode-neovim#code-navigation).
В отдельном Neovim назначения этих клавиш могут отличаться.

## Файлы, вкладки и список функций

| Клавиши | Действие |
| --- | --- |
| `\ff` | Найти и открыть файл по имени или части пути |
| `\sg` | Найти текст в файлах рабочей области VS Code |
| `gO` или `\ss` | Найти функцию, класс или другой символ в текущем файле |
| `\e` | Перевести фокус в Explorer |
| `H` / `L` | Предыдущая / следующая вкладка редактора — `Shift+h` / `Shift+l` |

В списках выбора VS Code: `↑` / `↓` или `Ctrl+n` / `Ctrl+p` — выбрать пункт,
`Enter` — открыть, `Esc` — закрыть.

На Mac также доступны **`Cmd+T`** для поиска символа по рабочей области и
**`Cmd+F12`** для перехода к реализации интерфейса или абстрактного метода.
Подробнее: [навигация VS Code](https://code.visualstudio.com/docs/editing/editingevolved).

## Между функциями и частями кода

Эти сочетания предоставляет Treesitter в LazyVim. Они доступны, когда для
языка установлен парсер с поддержкой textobjects.

| Клавиши | Действие |
| --- | --- |
| `]f` / `[f` | Следующее / предыдущее начало функции |
| `]F` / `[F` | Следующий / предыдущий конец функции |
| `]c` / `[c` | Следующее / предыдущее начало класса |
| `]a` / `[a` | Следующий / предыдущий параметр |

## По файлу и строке

Основные [движения Neovim](https://neovim.io/doc/user/motion/):

| Клавиши | Действие |
| --- | --- |
| `h` / `j` / `k` / `l` | Влево / вниз / вверх / вправо |
| `w` / `b` | Начало следующего / предыдущего слова |
| `e` | Конец слова |
| `W` / `B` | Как `w` / `b`, но границы — пробельные символы |
| `0` / `^` / `$` | Начало строки / первый непробельный символ / конец строки |
| `gg` / `G` | Начало / конец файла |
| `123G` или `:123` + `Enter` | Перейти к строке 123 |
| `5j` / `5k` | На пять строк вниз / вверх |
| `gj` / `gk` | Вниз / вверх по экранным строкам при переносе текста |
| `%` | Перейти к парной скобке |
| `}` / `{` | К следующей / предыдущей границе абзаца |
| `Ctrl+d` / `Ctrl+u` | На полэкрана вниз / вверх |
| `zz` | Разместить текущую строку в центре экрана |

Число перед движением задаёт повтор: `3w` — на три слова вперёд.
В твоём LazyVim `j` / `k` без числа тоже учитывают переносы строк.

## Найти текст или символ в строке

[Поиск Neovim](https://neovim.io/doc/user/pattern/) действует в текущем файле.
В [LazyVim](https://github.com/LazyVim/LazyVim/blob/main/lua/lazyvim/config/keymaps.lua)
`n` всегда ищет вперёд, а `N` — назад, даже после поиска через `?`.

| Клавиши | Действие |
| --- | --- |
| `/текст` + `Enter` | Искать вперёд в текущем файле |
| `?текст` + `Enter` | Искать назад в текущем файле |
| `n` / `N` | Следующее совпадение вперёд / назад |
| `*` / `#` | Искать слово под курсором вперёд / назад |
| `f{символ}` / `F{символ}` | Перейти к символу в строке вправо / влево |
| `t{символ}` / `T{символ}` | Остановиться перед символом по направлению движения |
| `;` / `,` | Повторить `f` / `t` / `F` / `T` в том же / обратном направлении |

Например, `f(` перемещает на следующую `(`, а `t(` — перед ней.

## Три привычных маршрута

- **Разобраться в реализации:** `gd` → прочитать код → `gb` вернуться → `gB` снова вперёд.
- **Подняться к вызывающему коду:** `gai` → открыть вызов → поставить курсор на имя окружающей функции → снова `gai`.
- **Найти нужную функцию:** `\ff` → открыть файл → `gO` → ввести имя функции.

Для начала достаточно запомнить **`gd`, `gr`, `gai`, `gb`, `gB`, `\ff`, `gO`, `/`, `n`, `%`**.
